Rust Axum REST API 接口文档

GET /api/random

从 SQLite 数据库随机获取一条高质量中英双语文案。

category 可选: math_logic | ai_ml | cs_geek | physics_stem
lang 可选: both (默认返回双语) | zh | en
tag 可选: 特定标签 (如 goedel / rlhf / docker)
format 可选: json (默认) | text (命令行单行纯文本)
GET /api/quotes

SQLite 全文与标签分页检索。

search 中英文关键词全文搜索
category 学科分类过滤
page / limit 分页控制 (如 page=1&limit=20)
GET /api/categories

获取所有学科分类元信息与当前入库数量统计。

POST /api/reload

热重载：将 JSON 种子源热同步入 SQLite 数据库。
